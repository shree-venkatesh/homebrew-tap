# shree-venkatesh/homebrew-tap

Homebrew formulae for shree-venkatesh's projects.

```bash
brew install shree-venkatesh/tap/<formula>
```

Or add the tap once and use short names:

```bash
brew tap shree-venkatesh/tap
brew install <formula>
```

## Formulae

| Formula | Description | Project |
| --- | --- | --- |
| `almost-arc` | Make Zen Browser look and behave like Arc | [Almost-Arc](https://github.com/shree-venkatesh/Almost-Arc) |

### almost-arc

```bash
brew install shree-venkatesh/tap/almost-arc
almost-arc install        # quit Zen first
```

After `brew upgrade almost-arc`, and after every Zen update, run `almost-arc install` again. To remove it, run `almost-arc uninstall`, then `brew uninstall almost-arc`.
